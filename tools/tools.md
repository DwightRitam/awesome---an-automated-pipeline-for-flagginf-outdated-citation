# Software Tools & Libraries

Core open-source packages, APIs, and libraries for parsing citations, resolving metadata, and computing vector embeddings.

---

* **habanero (Python Crossref Client)**
  * **Purpose:** Programmatic DOI resolution, bibliographic metadata extraction, and automated retraction notification checking.
  * **Link:** [habanero Repository](https://github.com/sckott/habanero)

* **GROBID Client Python (`grobid-client-python`)**
  * **Purpose:** Parsing scientific PDFs into structured TEI-XML/JSON, extracting references and inline citation markers.
  * **Link:** [grobid_client_python Repository](https://github.com/kermitt2/grobid_client_python)

* **Sentence-Transformers**
  * **Purpose:** Dense embedding generation for scientific text using pre-trained weights (`allenai-specter`, `all-mpnet-base-v2`).
  * **Link:** [Sentence-Transformers Repository](https://github.com/UKPLab/sentence-transformers)

* **Refextract**
  * **Purpose:** Reference extraction and normalization library designed by CERN to isolate citations from LaTeX and PDF sources.
  * **Link:** [refextract Repository](https://github.com/inveniosoftware/refextract)

* **FAISS (Facebook AI Similarity Search)**
  * **Purpose:** Vector similarity index library for fast dense retrieval over multi-million document scientific embedding indexes.
  * **Link:** [FAISS Repository](https://github.com/facebookresearch/faiss)

* **SciSpacy**
  * **Purpose:** spaCy pipelines tailored for scientific text, named entity recognition (NER), and claim candidate extraction.
  * **Link:** [scispacy Repository](https://github.com/allenai/scispacy)
