## Overview
Generative AI models and Large Language Model (LLM) search agents frequently recommend literature to support academic writing and factual claims[cite: 2]. However, AI models often rely on static training snapshots or web scraping that fails to track paper retractions, superseded empirical findings, updated standards, or literature drift over time[cite: 2]. An automated pipeline for flagging outdated citations serves as a crucial verification layer by linking recommended papers against real-time bibliographic databases, Crossref retraction registries, and citation graph evolution metrics[cite: 1, 2]. 

This domain integrates Natural Language Processing (NLP), semantic embeddings (such as SPECTER2), citation network analysis, and automated retraction monitoring[cite: 2]. This repository synthesizes foundational methodologies, recent algorithmic advances, datasets, and practical software tools to enable researchers and system builders to construct robust citation verification workflows[cite: 1, 2].

## Citation Integrity Audit
* **Audit Summary:** A systematic citation audit was conducted on 10 sampled references out of 41 total citations generated by LLM tools (Gemini 1.5 Pro, ChatGPT, Claude)[cite: 2]. 
* **Key Findings:** 
  * **Authenticity Score:** 90.0 / 100[cite: 2]
  * **Prediction Accuracy:** 90%[cite: 2]
  * **Verified (Code A):** 6 papers matched all metadata and persistent identifiers[cite: 2].
  * **Wrong Metadata (Code B):** 4 papers existed but contained title truncations or omitted author metadata in raw LLM web-scraping outputs[cite: 2].
* **Audit Report:** [View Full Citation Integrity Audit PDF](citation-audit/Citation_Integrity_Audit.pdf)[cite: 1, 2]

## Datasets
* **OpenAlex Academic Graph**  
  * **Source:** [OpenAlex Data Dump](https://openalex.org/)[cite: 2]  
  * **Description:** Fully open catalog of scientific papers, citations, authors, institutions, and concepts[cite: 2].  
  * **Application:** Used to query updated metadata, retraction statuses, and citation counts dynamically[cite: 2].

* **Semantic Scholar Academic Graph (S2AG)**  
  * **Source:** [Semantic Scholar Datasets](https://www.semanticscholar.org/product/api)[cite: 1, 2]  
  * **Description:** Open dataset of 200M+ papers with rich citation graphs and abstract embeddings[cite: 1, 2].  
  * **Application:** Essential for training semantic citation matching and document similarity systems[cite: 2].

* **Crossref Retraction Watch Database**  
  * **Source:** [Crossref Retraction Data](https://www.crossref.org/blog/news-crossref-and-retraction-watch/)[cite: 2]  
  * **Description:** Comprehensive database of retracted publications, reasons for retraction, and retraction notices[cite: 2].  
  * **Application:** Serves as the ground-truth registry for flagging invalidated literature in the automated pipeline[cite: 2].
